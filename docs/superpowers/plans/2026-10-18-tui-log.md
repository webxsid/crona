# TUI Log Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Log tab's three bordered tables (Sessions, Habits, Ops) with a Review-style strip and a `List │ Detail` layout, with the list grouped by day.

**Architecture:**
- Two shared pieces go in `views/chrome`:
  - `StripRows`, Review's strip packing, generalised
  - `DayList`, which draws the cursor's window of rows with non-selectable day dividers
- Each sub-tab view builds its own rows, strip and detail lines on top of them.
- The Sessions detail pane loads its data through a new preview command. The model debounces it whenever the selected session changes.

**Tech Stack:** Go, Bubble Tea, lipgloss, x/ansi, `viewchrome` (`RenderSection`, `JoinColumns`, `KeyHint`, `ListWindow`, `SelectionCursor`).

**Spec:** `docs/superpowers/specs/2026-10-18-tui-log-design.md`

## Global Constraints

- Tests: `cd tui && GOCACHE=/tmp/crona-go-cache go test ./...`. Never run `make fmt`; run `gofmt -w` on touched files only.
- UI-only: no daemon, API or details-dialog changes.
- Detail pane widths:
  - wide (≥160): `max(44, (W-6)*2/5)`
  - medium (≥100): `max(40, (W-3)*2/5)`
  - narrow: list only
- Day divider: `── <Mon 2 Jan> · <summary> ` padded with `─` to the width, dim, not selectable.
- **Grouping never reorders rows.** The list keeps the selection package's filtered order (`sessionmeta.FilteredSessionIndices`, the habit history order, the reversed ops), and the cursor stays a position in that order.
- Bottom row: global keys only. The help sheet keeps every key.
- Sessions preview: a debounce of 150 ms, fetched only when the width class is not narrow. A preview for any other session than the selected one is ignored.
- Commit on `brainstorm/tui-layout`.

## Review Focus

1. A filter that empties the list must not panic in `DayList`. The pane shows the sub-tab's empty line. (Test in Task 1.)
2. A cursor at the last row of a long list must keep its day divider visible when it is the day's first visible row. (Test in Task 1.)
3. A session with a nil `EndTime` or `DurationSeconds` renders `–now` and `0m`, and counts as 0 in the sums. (Test in Task 4.)
4. An Ops payload that is `nil`, a string, an array or a nested map renders without a panic, within the width. (Test in Task 3.)
5. A preview arriving after the selection has moved on must not replace the pane. (Test in Task 5.)
