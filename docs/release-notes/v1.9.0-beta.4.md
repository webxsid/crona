# Crona v1.9.0-beta.4

Crona v1.9.0-beta.4 makes same-day ad-hoc away mode reversible while preserving immutable historical away dates.

## Highlights

- Enabling ad-hoc away mode protects the current logical date without immediately appending it to canonical `awayDates`.
- Disabling away mode on that same date leaves no historical away entry.
- Once the logical date rolls over, the daemon records the completed date when away mode or a configured rest rule applied.
- Past canonical away dates remain stable and append-only.

## Fixes

- Live Momentum, streak, wellbeing, and accountability calculations continue to treat the current date as protected while away mode is active.
- Both enabling and disabling away mode invalidate the current Momentum snapshot so daemon and client views update immediately.
- Older provisional current-date entries are removed when away mode is disabled on that date.
- Editing rest rules during the current date no longer rewrites the preceding date's history.

## Compatibility

The local IPC protocol remains at `1.3`. Existing clients compatible with Crona v1.9.0-beta.3 do not require contract changes for this release.
