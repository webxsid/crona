# Crona v1.9.0

Crona v1.9.0 is a broad reliability and workflow release for the daemon, TUI, CLI, and companion-facing local IPC contract. It builds on v1.8.0's daemon-owned day-boundary scheduling with stronger timer controls, protected-day history, date-aware summaries, live-client synchronization, issue workflows, diagnostics, and documentation.

## Highlights

- Advance Pomodoro work and break segments early with `[z]`.
- Defer Pomodoro breaks through daemon-authoritative companion actions.
- Preserve Momentum and streak continuity across away and rest days.
- Explore focus scores and daily outcomes through the interactive Summary calendar.
- Keep connected clients synchronized across logical-day boundaries and reconnects.
- Create issues faster with dedicated save, create-more, and create-and-focus actions.
- Diagnose daemon behavior with preserved lifecycle logs and worker panic traces.
- Browse the new hosted documentation and API Reference.

## Added

- Pomodoro segment advancement from the TUI.
- Companion timer extension and break-deferral IPC actions.
- Daemon-issued break-deferral warnings, action acknowledgements, and one-shot segment extensions.
- Canonical historical `awayDates` handling with reversible same-day ad-hoc away mode.
- Historical away-date styling and recovery context in calendar, Daily, and Wellbeing views.
- Date-range focus-score dashboard responses with cause-oriented reasons: `no_activity`, `under_target`, `needs_breaks`, `balanced`, and `overextended`.
- Summary focus, rest, session, issue-outcome, and habit-outcome metrics.
- Interactive Summary score calendar with month navigation, score coloring, selection states, and away-date semantics.
- Richer date-range issue responses containing repository and stream names when available.
- Daemon lifecycle metadata, shutdown causes, and panic stack traces for worker failures.
- Hosted API Reference and reorganized guides, workflows, automation, migration, and development documentation.

## Changed

- Break deferral is daemon-authoritative and protected against duplicate concurrent requests and stale timer callbacks.
- Away-mode changes use the daemon-owned `settings.away_mode` operation.
- Momentum, streak, wellbeing, and accountability snapshots are invalidated when away or rest state changes.
- TUI date-scoped surfaces refresh together at Start of Day and reconcile logical date after reconnects.
- Scheduler wake-up, persistence, and boundary-delivery failures retry without stopping the daemon.
- Issue creation now supports `Ctrl+S` to save and close, `Ctrl+A` to create more, and `Ctrl+F` to create and focus.
- Create-more and create-and-focus preserve the selected repository and stream.
- Issue due and resolution dates use dedicated fields so long titles cannot hide them.
- Due-date pickers block past dates and configured future rest dates.
- Support navigation points to the documentation index.
- Daemon logs preserve the complete lifecycle instead of truncating on every write.

## Fixed

- Momentum continuity across protected daily, weekly, and monthly buckets.
- Same-day away-mode reversibility and prevention of premature historical entries.
- TUI startup panic during initial logical-date reconciliation.
- Missed or delayed day-boundary events after reconnects or scheduler delays.
- Duplicate break deferrals and immediate stale transitions after acknowledgement.
- Issue due-date binding display (`[d]`).
- Issue date visibility in Daily, Issues, and Meta layouts.

## Compatibility

- The local IPC protocol is now `1.5`.
- No storage migration is required.
- Companion clients using new timer actions, settings events, or date-range response fields should negotiate the corresponding protocol version before use.
- Existing data is retained; away-date normalization is handled by the daemon's existing settings/runtime logic.
