# Crona v1.9.0-beta.5

Crona v1.9.0-beta.5 improves TUI support navigation, expands dashboard IPC, advances the local protocol to 1.4, and makes configured day boundaries reliable across live clients.

## Highlights

- The Support view's `[g]` action now opens the Crona documentation index instead of the roadmap.
- The beta support menu uses the same documentation destination and updated wording.
- The Set Issue Status dialog now identifies the selected issue with its title, repo, stream, current status, and worked-versus-estimate summary.
- The dashboard now exposes a date-range focus-score endpoint for calendar and range views.
- The TUI refreshes issues, daily plans, habits, summaries, wellbeing, Momentum, and rollups together when the configured Start of Day occurs.
- The TUI reconciles its logical date from daemon health after reconnecting, including when the boundary event was missed.
- Day-boundary scheduler failures are retried without stopping the daemon, and delayed scheduler wake-ups catch up the logical Start of Day transition.

## Protocol

- The local IPC protocol is now `1.4`.
- Clients using the new dashboard focus-score range method must negotiate protocol `1.4`.

## Compatibility

The local IPC protocol is `1.4` for this release.
