# Crona v1.9.0-beta.1

Crona v1.9.0-beta.1 adds Pomodoro timer segment advancement from the TUI and extends the local IPC timer contract for client-visible timer controls.

Highlights:

- Add a `[z]` TUI binding to advance Pomodoro work and break segments early.
- Add timer extension support for companion clients.
- The local IPC protocol version is now `1.2`.
