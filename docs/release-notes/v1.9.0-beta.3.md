# Crona v1.9.0-beta.3

Crona v1.9.0-beta.3 fixes Momentum continuity across protected away and rest days.

## Highlights

- Daily Momentum streaks remain continuous when a completed day is followed by a protected day and then another completed day.
- Canonical away-date changes invalidate affected snapshots, allowing the daemon to rebuild Momentum from authoritative historical rest data.
- Connected TUI clients reload Momentum, streak, wellbeing, and rollup surfaces when relevant away or rest settings change.

## Fixes

- Snapshot-based Momentum no longer restarts at one after resuming from a protected daily bucket.
- Protected-bucket continuation is consistent for habit and context targets across daily, weekly, and monthly periods using either `any` or `all` matching.
- A genuine unprotected miss after protected days still resets the current streak while preserving the longest streak.

## Compatibility

The local IPC protocol remains at `1.3`. Existing clients compatible with Crona v1.9.0-beta.2 do not require contract changes for this release.
