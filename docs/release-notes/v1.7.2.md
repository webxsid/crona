# Crona v1.7.2

Crona v1.7.2 is a small TUI hotfix for the view-jump menu.

## Fixed

- The view-jump menu now keeps `[y]` for History and moves Summary to `[g]`, avoiding the duplicate mnemonic that made one of the destinations unreachable by key.
- A regression check now covers the full view-jump menu so duplicate mnemonic keys are caught in tests.

## Compatibility

- This patch does not change the local IPC protocol version or require a storage migration.
